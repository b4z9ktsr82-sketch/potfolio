01 — Biography

Hi, I'm Saqib.

I'm a Front-End Web Developer and a Software Engineering student at the University of Swat. I build clean, responsive web interfaces that work well on all devices. Because my learning comes from formal study and not only from tutorials, I treat a web page the same way I treat a program, paying close attention to structure, readability and maintainability.

My programming base comes from C++ and Object-Oriented Programming. That's where I learned to think through logic, break problems into smaller parts and work with classes, inheritance and encapsulation. The same thinking shows up in how I write markup and styles: I use semantic HTML, keep my CSS organised and reusable, and use Bootstrap for layouts that adjust well to different screen sizes.

I also completed an 8-week Artificial Intelligence course at the AI Institute. It covered Python, prompt engineering, AI and machine-learning engineering concepts, practical AI tools, Canva and freelancing. It gave me two useful things: a second language in Python, and the ability to use AI tools properly inside real development work — for debugging, understanding unfamiliar code and learning faster.

Right now I'm learning JavaScript so I can add interactivity to the interfaces I build, and that's where most of my learning time goes. I'm building projects that turn what I learn into real work rather than repeating tutorials.
